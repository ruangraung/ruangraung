## What I build

- [**apple-intelligence-report-parser**](https://github.com/ruangraung/apple-intelligence-report-parser): Reads the Apple Intelligence Report JSON that macOS exports from Settings > Privacy & Security > Apple Intelligence Report, and writes CSV, HTML, TXT, Markdown, and JSON you can actually read. Stdlib-only Python. No dependencies, no installer, no network access, ever.
- [**precontext-screen**](https://github.com/ruangraung/precontext-screen): a Hermes plugin that screens untrusted web pages for prompt injection before they reach an agent's context, and fails open when screening is not available.
- [**bumblebee-gui**](https://github.com/ruangraung/bumblebee-gui): A web interface for [Bumblebee](https://github.com/perplexityai/bumblebee), the open source supply chain security scanner from Perplexity AI. This is an unofficial interface for that scanner. It is not affiliated with or endorsed by Perplexity AI. Bumblebee walks a filesystem, reads package metadata across a dozen ecosystems, and reports anything that matches a published compromise. It is a CLI, which suits some people and not others. Bumblebee GUI wraps it in a web app: point it at a directory, run a scan, watch progress stream in, and read the result as a table you can filter, sort and export.
- [**Bumblebee Report Parser**](https://gist.github.com/ruangraung/f159a0936bd85e67bd63965bbb131b64): one script that reads [Bumblebee](https://github.com/perplexityai/bumblebee)'s NDJSON reports on macOS, Linux, and Windows.

Forks I work inside rather than just clone: [hermes-agent](https://github.com/ruangraung/hermes-agent), the agent I run my own tooling from, plus [mnemosyne](https://github.com/ruangraung/mnemosyne) and [hermes-lcm](https://github.com/ruangraung/hermes-lcm) for memory and context.

Several music projects are in progress and still private. 🎹🎶🥁🎸 They will show up here when they are worth reading.
